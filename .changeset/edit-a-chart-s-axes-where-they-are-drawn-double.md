Edit a chart's axes where they are drawn. Double-click a numeric axis to set its range in a popover beside it, or double-click an axis title (or press Enter on it) to rename it in place. The axis context menu adds Set range, Fit to the data, and Edit axis title. `PopoverContent` accepts a `container` so popovers inside a modal dialog can take focus.
