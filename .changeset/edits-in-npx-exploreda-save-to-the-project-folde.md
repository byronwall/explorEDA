Edits in `npx exploreda` save to the project folder a moment after you make them, rewriting only the files that changed, and the app reloads when a file changes on disk, such as after `git pull`. `ExplorEdaProject` now reports only field settings that differ from the project's declared names and types. Dashboard text no longer writes a bare `rows` line for a Rows view left at its defaults.
