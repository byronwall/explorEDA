# Reproduce an analysis beyond the current renderer

## My read

Developers may need to reproduce the meaning of an analysis independently of the mounted React workspace. Current saved settings can reopen the app, and several planners retain traceable intermediate values. The broader outcome is a repeatable analytical result with known source identity, parameters, filter scope, and contributor membership.

This is a future architecture seed, not a mandate for a universal scene graph. First distinguish semantic reproduction from identical pixels. A headless result that agrees on values and source IDs can prove more than a screenshot. A later rendering contract should grow only from an export, testing, or alternative-renderer task that requires it.

This remains a future seed. Its expansion trigger is a proposed decision rule, not a release commitment.

## What matters most

- Bind replay to a source and its record meaning.
- Separate semantic agreement from visual reproduction.
- Keep provider and renderer changes outside the first proof.

## The intended experience

Capture one chart’s source binding, settings, and effective population. Evaluate its analytical result locally without mounting the workspace. Compare values, exclusions, and contributors with the current chart. Only later, if needed, draw that result through a second renderer or export path.

## Boundaries

Do not equate positional IDs with stable cross-reload identity. Source versions and fingerprints are candidates, not selected infrastructure. Avoid a general scene schema, compiler platform, or complete chart rewrite. The Pro prototype is historical research and must not be copied into active source as accepted implementation.

## What seems settled

Current DSL compilation/export and saved settings are delivered and reusable. Renderer-neutral replay remains a separate possible extension. The original deterministic-rendering initiative’s completed traces do not establish the broader contract.

## Current reality that matters

The archive includes a Pro scatter planning prototype and verification files. Active scatter and time-series planners now offer narrower real seams. SavedAnalysisStructure stores rows and settings, but no general renderer-neutral analytical result catalogue.

## Expansion trigger

Expand when an external export, independent verification process, or second renderer needs more than reopening the same React component.

## Next step after confirmation

Evaluate one active scatter plan twice from a fixed source and settings. Compare semantic output with the mounted trace. Decide whether a small headless API meets the need before designing a broader interchange format.
