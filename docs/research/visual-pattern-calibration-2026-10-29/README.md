# Calibrating visual pattern judgments in pair discovery

Propose an offline, blinded evaluation of the implemented Scatter Matrix / Pairs / original Scatter workflow. Does combined coefficient and plot evidence help readers distinguish association from chance, recognize nonmonotonic structure, and interpret coefficient disagreement? Does representation change their judgments? This note specifies a bounded first experiment and a separate later search experiment. It reports no participant results, product defect, validated efficacy, or deployment status. No in-app lineup mode is proposed.

## Literature: what transfers and what does not

**Buja et al., _Statistical Inference for Exploratory Data Analysis and Model Diagnostics_, published November 13, 2009**, DOI [10.1098/rsta.2009.0120](https://doi.org/10.1098/rsta.2009.0120). Sources: [author paper, sections 3–5](https://vita.had.co.nz/papers/inference.pdf); [university date record](https://research.monash.edu/en/publications/statistical-inference-for-exploratory-data-analysis-and-model-dia/).

The classical lineup randomly places one real plot among null plots; a blinded observer chooses the most different. Null generation is explicit. Under exchangeable independent rows and pair independence, permuting one coordinate preserves empirical marginals while breaking association. Seeing the target first compromises blindness. These principles motivate our design; they do not justify arbitrary shuffling for clustered or time-dependent records or automatically validate our experimental variants.

**Li, Cook, Tanaka and VanderPlas, _A Plot Is Worth a Thousand Tests: Assessing Residual Diagnostics with the Lineup Protocol_, published online May 22, 2024**, DOI [10.1080/10618600.2024.2344612](https://doi.org/10.1080/10618600.2024.2344612). Sources: [author thesis chapter, sections 2.4–2.6](https://thesis.patrickli.org/02-chap2); [publication record](https://srvanderplas.github.io/posts/papers/liplotworththousand2024.html); [reproducibility repository](https://github.com/TengMCing/lineup_residual_diagnostics).

Their human experiment used simulated residual-versus-fitted plots. Appropriate conventional tests detected weaker departures than viewers. A small left/right triangular heteroskedasticity detection asymmetry, despite symmetric numerical comparisons, motivates a representation probe. This does not establish universal visual superiority, harmless small effects, or valid raw-pair discovery. The repository contains reproducibility materials; no downloaded code was executed. All sources were accessed October 29, 2026.

## First experiment: preselected pairs, offline

Everything below is proposed. Start with named hypotheses and a frozen trial manifest before generating participant-facing stimuli. No unrestricted pair selection in this phase. A maintainer can render matched evidence offline using the current coefficient and scatter semantics; original Scatter comparisons must be prepared explicitly with identical source rows and settings, without claiming a new continuation control exists.

**Bounded stimulus plan.** Generate independent rows with X uniform on [−1, 1] and independent standard normal noise Z. Use n = 40 and 120; noise multiplier sigma = 0.25 and 1.0. For each cell, generate four fresh seeded realizations of Y = X + sigma Z (linear), Y = exp(2X) + sigma Z (monotonic curve), Y = X² + sigma Z (U), and Y = sigma Z (unrelated). This gives 64 base targets, not 64 trials per participant. Sigma is a declared generator parameter, not an equal effect-size claim across shapes. Fix seeds in a concealed answer manifest; publish seeds only after collection. Do not screen seeds for attractive plots, a desired coefficient gap, or an especially convincing target. Record realized coefficients as continuous annotations for analysis rather than selecting winners by them.

Start without ties, missingness, colors, facets or date axes. A later separately reported stratum can add quantization and a declared missingness mechanism. Freeze the complete-pair IDs before producing any evidence condition or null and retain exclusion reasons; never let a permutation silently change the cohort. Groups need their own cohort declarations and reranking, with pooled results separate. Clustered and time-dependent data are deferred until an explicit defensible null model exists.

**Evidence conditions.** Assign coefficient-only (r, rho, n), plot-only (original measurements, n), and combined evidence using matched generator/size/noise blocks and randomized assignment. Keep numeric precision fixed to the current two-decimal Pairs display, and save unrounded results for analysis. A reader never sees the same underlying target, its reflection, or its null derivatives in another condition. Counterbalance condition order and use disjoint practice stimuli. Hide filenames, descriptive field names, generator labels, seed IDs, answer metadata and target position; use neutral identifiers. Keep the answer key inaccessible to the observer and facilitator during collection. Record any prior target exposure; exclude compromised trials from blinded analysis and disclose them.

Separate two tasks rather than merging their scores:

1. **One-target lineup.** One generated target in a uniformly randomized position among 19 null panels. In plot-only form this follows the classical layout. Coefficient-only and combined versions are experimental evidence variants, not already validated lineup tests. Ask for the most different panel and a shape explanation. Record a forced choice separately from an optional “insufficient evidence” confidence response.
2. **Calibration/classification.** Mix target-containing and all-null trials, conceal trial type, and permit “none / insufficient evidence.” Ask whether evidence supports linear, monotonic curved, nonmonotonic, or no discernible association; allow “unsure.” An all-null trial has no designated real target and is not a conventional lineup test. Report how often readers assert structure anyway. A noisy unrelated realization can look structured by chance: generator truth and the reader's visible description must both be retained.

**Null and display contract.** For the initial independent-row pair-independence null, hold X and permute Y's row positions independently for each null panel. Keep n, each marginal, units, and complete-pair membership fixed. Record the null algorithm and permutations; jointly permuting X and Y together would preserve the association and is not this null. Shared target-derived nulls introduce dependence between panels and repeated responses; do not count them as independent experimental replicates. All-null calibration trials start from a fresh independent X/Y draw under the declared null. No automatic p-values are produced in either task.

Use one predeclared domain rule across all panels in a trial, based symmetrically on the pooled panel values, with no clipping, per-panel auto-zoom or target-only padding. Fix dimensions (for example 180 × 180 CSS pixels per panel), point radius, opacity, color, ticks and neutral labels; log the actual rendering settings. Fix any Scatter overlays off in all conditions. Keep the first representation contrast to X-axis reversal applied to every panel in a trial, with axis values labeled accurately. Assign reversed variants to different readers; recompute no coefficients. This is a controlled orientation probe motivated by Li et al., not a replication of their heteroskedasticity experiment. Matrix-versus-full-Scatter size/layout comparison comes later, with cohort and settings held fixed and the representation change named explicitly.

## Controls, outputs and decisions

Before asking reviewers to participate, inspect generated assets for filename/metadata leaks, hidden answers, accidental scaling cues, missing marks and unreadable labels. Independently verify pairing, coefficients and null membership against a small hand-checkable fixture. Strong linear and U cases are positive controls; fresh independent pairs and all-null trials are negative controls. If controls fail, first distinguish a broken stimulus or instruction from a perceptual limit. The implemented-example Spike case is not the focus of this experiment.

Capture anonymous reader ID, trial/condition/order, selected panel, shape classification, explanation, confidence, elapsed time, abstention and prior exposure. Do not infer correctness from confidence or speed alone. Return:

- Detection tables by generator, n, sigma and evidence condition, including misses and abstentions, with denominators.
- Confusion tables for intended generator versus perceived structure, plus coefficient-disagreement explanations; a gap is not proof of a particular mechanism.
- False-alarm tables for unrelated and all-null trials, separated from one-target identification rates.
- Representation contrasts and uncertainty intervals with the method stated. Respect reader and base-stimulus dependence in resampling or modeling; small strata may support descriptive ranges only. Retain trial-level counts and avoid treating every panel judgment as a new person.

A handful of internal reviewers supplies formative feedback, not validated efficacy. Freeze the pilot trial budget and stopping rule before collection; do not keep adding readers or seeds until a favorable comparison appears. Stop and repair the protocol if blinding, cohort identity or rendering consistency fails; recollect with fresh stimuli after material revisions. Before a larger study, choose participant recruitment, sample size, estimands and meaningful decision margins from pilot uncertainty and the intended use. This note invents no universal performance pass threshold.

The first review decision is whether the probe can distinguish misunderstanding from ambiguous stimuli. If combined evidence has no clear benefit, intervals remain broad, or false alarms increase, preserve the current UI and report the limits. Repeated confusion may justify a narrowly scoped documentation/example experiment first. Any UI proposal requires independent confirmation on fresh stimuli and its own design review; a positive pilot alone does not authorize implementation.

## Later experiment: calibrate the whole search

Selecting the strongest of up to 45 pairs, then evaluating only that winner, retains selection leakage. A successful preselected-pair probe cannot validate unrestricted pair search. A separate end-to-end track must regenerate the entire multivariate dataset under an explicit null and rerun field inclusion, all pair computations, sorting (including canonical ties), search/filter actions and the reader's selection process. Log the allowed actions and stopping rule. Compare selection outcomes under that complete procedure, not a null distribution for one fixed pair retrofitted to the winner. Independence assumptions for a multivariate null and adaptive reader actions need methods review before any inferential claim.

Concrete next work, if this note is accepted: review the manifest/null contract; build and audit an offline stimulus set; conduct the bounded formative pilot; return the detection/confusion/false-alarm tables and protocol failures; decide whether to stop, refine documentation, or design a larger fresh-stimulus study. Search-wide calibration remains a separate later decision. Results may support no product change.
