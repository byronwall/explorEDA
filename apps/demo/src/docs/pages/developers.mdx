## Quick start

Install the package. It works with React 18 or 19.

```bash
pnpm add exploreda
```

Import the component and its stylesheet, then pass your rows. `data` is the only required prop; the workspace starts with a field summary and, in the next grid spot, a few first charts drawn from your fields.

```tsx
import { ExplorEda, stringifySavedData, type ExplorEdaProps } from "exploreda";
import "exploreda/dist/ExplorEda.css";

export function Analysis({ rows }: { rows: ExplorEdaProps["data"] }) {
  return (
    <ExplorEda
      data={rows}
      onStateChange={(settings) =>
        localStorage.setItem("analysis", stringifySavedData(settings))
      }
    />
  );
}
```

To reopen a saved analysis, pass what `onStateChange` gave you back as `savedData`.

<Callout type="warning" title="savedData is not a controlled value.">
  Pass it to restore a workspace, the first time or to replace one. Don't feed
  every `onStateChange` result back into it; the workspace already holds those
  edits.
</Callout>

### New rows, same saved analysis

A brushed selection is saved by row position. If you pass new `data` and keep the same `savedData`, the workspace moves each saved position to the new row with the same values. A selection keeps its records when rows are reordered or added.

If a selected record is gone, has changed, or now appears twice, its filter is dropped and every row shows. The filter never picks another record in that record's old place.

New `savedData` passed together with the new `data` is applied as given, since it was saved for those rows. To start fresh, pass the new `data` without `savedData`.
