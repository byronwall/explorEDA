## Trace a mark

Trace explains how a mark was computed: its source values, calculations, filters, scales, and position. It works on every chart type except 3D scatter plots, data tables, pivot tables, summary tables, and notes.

- Use the trace button in a chart's header to choose a chart object.
- Or Alt-click a point, chart title, axis object, color label, or facet label. Alt-Enter traces the focused title, facet, or color scale.
- A normal click keeps selecting and filtering.

From a trace, find the source rows behind the mark.
