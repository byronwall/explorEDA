# Three things in the 2023 NFL data

The database holds the 2023 NFL season: 285 games (regular season and playoffs), a table of about 25 thousand players, and a play-by-play table with every snap. Each finding below is computed from the database through explorEDA.

```eda
eda query=findings
kind:cat=findings.kind label=Kind
label:cat=findings.label label=Label
grp:cat=findings.grp label=Group
value:num=findings.value label=Value
```

## 1. Home teams win by a few points, but a single game is close to a toss-up

```eda
calc home_win = value > 0 ? 1 : 0
metric @home_wins avg(home_win) title="Share of games the home team won (ties count as not won)" where.kind=margin
metric @home_margin avg(value) title="Average home margin (points)" where.kind=margin
hist @margin value bins=30 title="Home score minus away score, per game" where.kind=margin {
  x.title="Home margin (points)"
  rule x=0 "Tie"
}
```

Home teams won 56.5% of the 285 games and finished 2.9 points ahead on average. That edge is small next to the spread of results, which runs from blowout losses to blowout wins, so home field helps but does not decide a game.

## 2. Some offenses are worth far more per snap than others

```eda
group @team_epa avg(value) by=label
row @team_rank label group=team_epa title="EPA per pass or run play, by team" where.kind=team topN=32 {
  x.title="Average EPA per play"
}
```

EPA is expected points added on a play. San Francisco led at about +0.17 points per pass or run play, then Buffalo at +0.11. The Jets were last at about -0.25, with Patriots, Panthers and Giants close to -0.2. That gap is large.

## 3. Passing wins early in the series; running wins on third and fourth down

```eda
group @down_epa avg(value) by=label
row @pass_down label group=down_epa title="Passes: EPA per play by down" where.kind=down where.grp=pass {
  x.title="Average EPA per play"
}
row @run_down label group=down_epa title="Runs: EPA per play by down" where.kind=down where.grp=run {
  x.title="Average EPA per play"
}
```

On first down a pass adds about +0.03 points and a run loses about 0.10. On second down the pass still leads (+0.02 against -0.04). The order flips on third down (run +0.07, pass -0.10) and on fourth (run +0.60, pass -0.35). That is partly selection: teams run on short-yardage downs, where a run is likely to convert. It is a pattern in the data, not proof that teams should run more on late downs.
