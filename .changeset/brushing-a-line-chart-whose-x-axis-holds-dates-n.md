Brushing a line chart whose x axis holds dates now keeps the rows in the dragged range instead of filtering every row out, and a calendar brush to the right edge ends on the last period. Date pickers no longer offer plain numeric columns as dates, numeric timestamps work in calendar charts, and box plots draw one box for missing groups, keep standard-deviation whiskers on the axis, ignore an empty violin bandwidth, and explain a field with no numeric values.
