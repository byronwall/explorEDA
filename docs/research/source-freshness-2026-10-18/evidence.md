## Primary sources independently opened

These checks support the boundary. They do not certify installed servers, permissions, or arbitrary SQL. Access date: 2026-10-19.

| Source                                                                                                                                                 | Checked meaning and limitation                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [SQLite isolation](https://www.sqlite.org/isolation.html), [transactions](https://www.sqlite.org/lang_transaction.html)                                | Separate connections see committed changes. WAL lets a read retain its view while another connection commits. Deferred BEGIN establishes the view at its first read. Separate completed statements can straddle commits. |
| [PostgreSQL isolation](https://www.postgresql.org/docs/current/transaction-iso.html)                                                                   | Repeatable-read statements use a transaction view. Current driver selects that level. Separate refresh sessions do not share it. Documentation route displays PostgreSQL 18.                                             |
| [MySQL 8.4 transaction start](https://dev.mysql.com/doc/refman/8.4/en/commit.html)                                                                     | WITH CONSISTENT SNAPSHOT applies to InnoDB and does not set isolation. Outside REPEATABLE READ, the modifier is ignored with a warning. Current eligibility is unverified.                                               |
| [SQL Server isolation](https://learn.microsoft.com/en-us/sql/t-sql/statements/set-transaction-isolation-level-transact-sql?view=sql-server-ver17)      | READ_COMMITTED behavior depends on RCSI. SNAPSHOT needs database eligibility. One joined query is not a universal remedy under the present driver. No operator setting was changed.                                      |
| [DuckDB transactions](https://duckdb.org/docs/current/sql/statements/transactions), [concurrency](https://duckdb.org/docs/current/connect/concurrency) | Snapshot isolation is documented. Embedded READ_ONLY excludes writers while open. Reads that close and reopen can straddle changes. Remote modes are outside the current driver proof.                                   |
| [Metabase caching](https://www.metabase.com/docs/latest/configuring-metabase/caching)                                                                  | Cache validity describes stored query-result age. It does not establish a common database view for several questions.                                                                                                    |
| [Tableau freshness policy](https://help.tableau.com/current/online/en-us/data_freshness_policy.htm)                                                    | The policy governs query caches for eligible live workbooks. It excludes Desktop and extract/file workbooks. It supplies no cross-source consistency guarantee.                                                          |
| [Power BI enhanced refresh](https://learn.microsoft.com/en-us/power-bi/connect-data/asynchronous-refresh)                                              | Transactional and partialBatch modes control model commits and failure retention. This supports a publication distinction, not an upstream consistency claim.                                                            |
