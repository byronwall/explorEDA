## How it reads

<ReadingGuide chart="hierarchy">
  <Part at="level">
    Levels are category fields from outermost in, one to three. Each row is one
    path through them.
  </Part>
  <Part at="size">
    Node size is a count of rows, or a sum of a measure. Negative and missing
    measure values are left out.
  </Part>
  <Part at="color">
    Nodes are colored by their first-level branch, by level, or in one color.
  </Part>
  <Part>
    **Arrangement** draws the same hierarchy as a treemap, an icicle, or a
    sunburst.
  </Part>
  <Part>
    Zoom into a branch to see its parts; the zoom saves with the chart.
  </Part>
</ReadingGuide>
