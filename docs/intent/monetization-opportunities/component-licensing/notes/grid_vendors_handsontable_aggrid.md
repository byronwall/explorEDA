# JavaScript grid and spreadsheet vendors: licensing, pricing, enforcement (checked 2026-10-10)

All pricing pages and npm/GitHub counts below were checked on **2026-10-10** unless a different date is noted. "Verified" means read directly from the cited page; "inference" is my reading of the evidence. Prices change often; the per-vendor sections record the exact page used.

## Handsontable case study (license change, reaction, key mechanics, pricing, SaaS/OEM)

### Takeaway
Handsontable went from MIT to a custom "free for non-commercial and evaluation" source-available license with v7.0.0 on 2019-03-06, explicitly because a 1:25 paid-to-free ratio from the old CE+Pro open-core split could not fund the company. The move drew a 112-point / 73-comment HN thread but npm downloads kept growing (roughly 143K/month in March 2019 to about 1.49M in the last 30 days as of 2026-10-08). Enforcement is an offline-validated `licenseKey` that blocks the grid with an uncloseable modal when missing or invalid, but never stops a paid grid when the key merely expires. Public pricing has disappeared behind "Contact sales"; the reseller list price is about $979 per developer per year (minimum 2 developers), per application, unlimited end users.

### Cited Findings

**The 2019 change and its stated rationale**
- The 2019-03-04 blog post "Handsontable drops open source for a non-commercial license" (author Chris Spilka) says sustaining a business on open source "has become much harder," competition in dev tools has grown since the project started in 2011, Handsontable CE was largely funded by Pro sales, and "the ratio of commercial to free users is about 1 to 25," which did not cover costs. — [Handsontable blog](https://handsontable.com/blog/?p=1263)
- Same post: with v7.0.0 the MIT license was replaced with a custom "free for non-commercial and evaluation" license; Handsontable Pro was merged into CE so there is "only one Handsontable"; the Pro npm package was deprecated and the Pro GitHub repo archived; code stays on GitHub and PRs are still reviewed; users who cannot accept the new license may buy a commercial license or stay on 6.2.2. The company also pledged 1% of monthly net profit to open source creators. — [Handsontable blog](https://handsontable.com/blog/?p=1263)
- The v7.0.0 release post (2019-03-06, Peter Plesa) describes the software as "source-available" rather than "open source." — [Handsontable 7.0.0 release post](https://handsontable.com/blog/?p=1299)
- Current docs: "Handsontable was previously MIT-licensed. The last version under permissive terms was 6.2.2, released on December 19, 2018." Non-commercial use covers "research, private study, and evaluation"; commercial use is "strictly limited to evaluation, development and testing tier," and "you can't enter the production stage if your project is in any way connected with your commercial activity." — [Software license docs](https://handsontable.com/docs/javascript-data-grid/software-license/)
- Before the change, a Handsontable forum thread records the Developer Licence at "$590 per developer," with staff explaining a developer "can use the license on multiple websites but you can't share the license with a colleague"; a software directory later listed "Developer USD 790.00" as a one-time perpetual price (undated). — [Handsontable forum](https://forum.handsontable.com/t/handsontable-developer-license/1539); [Techimply listing](https://www.techimply.com/profile/handsontable)

**How the license keys work**
- `licenseKey: 'non-commercial-and-evaluation'`: "With this key, the grid displays no notification of any kind, and the console stays silent." It is for teaching, research, evaluation, and testing. — [License key docs](https://handsontable.com/docs/javascript-data-grid/license-key/)
- Commercial keys are 25-character strings (`'00000-00000-00000-00000-00000'`) or newer plain-English "entitlement" keys followed by a bracketed block; older 25-character keys keep working. — [License key docs](https://handsontable.com/docs/javascript-data-grid/license-key/)
- Validation is offline: it compares the build date of the Handsontable version with the creation date in the key; "This process does not trigger any connection to any server." Trial and subscription entitlement keys also carry an expiration date checked against the current UTC date. — [License key docs](https://handsontable.com/docs/javascript-data-grid/license-key/); the React wrapper readme also states the key "is validated offline, with no connection made to any server." — [awesome.ecosyste.ms mirror of react-handsontable readme](https://awesome.ecosyste.ms/projects/github.com%2Fhandsontable%2Freact-handsontable)
- Missing or invalid key: "A modal that cannot be closed covers the grid, and the same message appears in the console." Expired perpetual or subscription key: the grid keeps working; a message appears below the table and in the console ("never stops working" for subscriptions). Expired trial: message by the badge and below the grid plus a console error, then a blocking screen after a grace period. Using a version newer than a perpetual key's date shows a console error and a notice below the table (the FAQ calls it a watermark). No row-count limit is mentioned. — [License key docs](https://handsontable.com/docs/javascript-data-grid/license-key/)

**Current non-commercial license text**
- The non-commercial license v3.0 (dated 2026-01-22, issued by HANDSONCODE sp. z o.o., covering both Handsontable and HyperFormula) grants a royalty-free, irrevocable copyright license for strictly non-commercial purposes (education, research, personal use, testing, demonstration). In commercial or institutional settings it allows only internal evaluation in non-production environments for "a single, non-renewable period of ninety (90) consecutive calendar days" (section 2.2(b)). The v1.0 text dated 2025-11-20 allowed thirty days and covered only Handsontable. — [Non-commercial license PDF v5 directory](https://handsontable.com/static/licenses/non-commercial/v5/handsontable-non-commercial-license.pdf) (document headings only were machine-readable; the 90-day and 30-day quotes come from the search index of the same PDFs); the earlier v4 PDF is at [this URL](https://handsontable.com/static/licenses/non-commercial/v4/handsontable-non-commercial-license.pdf)

### Inferences
- The license switch did not dent adoption in download terms: monthly npm downloads roughly doubled within three years of the change and are about 10x the pre-change level today. Download counts include non-commercial and CI use, so they are a ceiling on, not a proxy for, paying customers.
- Handsontable's "non-commercial key as a plain string" design means enforcement is honor-system for the free tier and offline-cryptographic only for the paid tier. The vendor relies on the uncloseable modal plus legal terms, not phone-home, which is attractive for a solo developer (no license server to run).
- Moving pricing behind "Contact sales" while the reseller still lists ~$979/dev/year suggests a deliberate shift to sales-led, enterprise-priced deals since roughly 2024-2025. The 2025-2026 license rewrites (v1.0 on 2025-11-20, v3.0 on 2026-01-22) and the move of HyperFormula to GPLv3 suggest ongoing tightening of free use.
- The per-developer-per-application unit with unlimited end users means a SaaS vendor pays only seats, not deployment fees; OEM/redistribution appears to be handled by the Enterprise contract rather than a published SKU.

### Gaps
- The GitHub issue #5831 thread (the primary venue for the 2019 reaction) has been moved to a repository that is not publicly accessible; the GitHub API returns 301/404, so comment counts and staff replies could not be recovered.
- The actual text of the commercial/subscription license (SaaS, OEM, sublicensing clauses) is in PDFs whose body text could not be extracted; only the reseller's one-line scope statement was readable.
- No public revenue figure for Handsoncode; Gartner's "<50M USD" field is ambiguous and unverified.
- Handsontable's own list prices before 2019 could not be verified beyond the $590 forum figure and an undated $790 directory figure.
- GitHub star history around 2019 was not found.

## AG Grid case study (Community vs Enterprise, enforcement, pricing, company)

### Takeaway
AG Grid pairs an MIT Community package with a commercial Enterprise package that ships on public npm, runs without a key for local testing, and shows a watermark plus console error until a key is installed. List price is $999 per developer (perpetual, 1 year of updates), $1,498 for the Grid+Charts bundle, sold per developer and per deployment with a 30-day production-grade trial. Founder Niall Crosby started solo in 2015, launched Enterprise in 2016 at £250 per developer, hit 1,000 enterprise customers in 2017, and the company is now ~60 people, self-funded until a 2025 Adelis-backed combination with Bryntum.

### Cited Findings

**License split and gated features**
- README: "`ag-grid-community` is licensed under the MIT license." "`ag-grid-enterprise` has a Commercial license." Repo stars 15.6k. — [GitHub ag-grid/ag-grid](https://github.com/ag-grid/ag-grid); GitHub API shows 15,631 stars and a NOASSERTION license field (mixed licenses in one repo). — [GitHub API](https://api.github.com/repos/ag-grid/ag-grid)
- Community: sorting, filtering, pagination, custom cell rendering, themes, accessibility, row/column virtualization, React/Angular/Vue/JS. Enterprise: Server-Side Row Model, Excel Export, Pivot Tables & Aggregations, Range Selection, Integrated Charts, Master/Detail, Row Grouping & Multi-Column Sorting, Clipboard Operations, Tool Panels, Custom Context Menu & Sidebars. "All Enterprise features are marked with an (Enterprise) [icon] in our docs." The page also says "Both AG Grid Community and Enterprise are open source" while Enterprise "requires a commercial EULA licence." — [Community vs Enterprise](https://www.ag-grid.com/javascript-data-grid/community-vs-enterprise/)
- cdnjs lists `ag-grid-enterprise` 33.0.0 as "Commercial see LICENSE.txt." — [cdnjs](https://cdnjs.com/libraries/ag-grid-enterprise/33.0.0)

**Enforcement, trial, key install**
- "You can test AG Grid Enterprise locally without a licence." To test in production, access support, and "remove the watermark & console warnings," request a trial licence. The key is set with `LicenseManager.setLicenseKey("YOUR_LICENSE_KEY")` from `ag-grid-enterprise`. — [License install docs](https://www.ag-grid.com/javascript-data-grid/license-install/)
- Without a key Enterprise "will display a watermark and an error message in the console." Licences are sold "on a per-developer, per-deployment basis," are "perpetual," with "1 year of support and updates." — [Licensing docs](https://www.ag-grid.com/javascript-data-grid/licensing/)
- Free 30-day Enterprise Bundle trial: full AG Grid and AG Charts Enterprise features, "no console warnings or watermarks," Zendesk engineering support, and use "without restrictions in a production environment." — [License pricing page](https://www.ag-grid.com/license-pricing/); [Licensing docs](https://www.ag-grid.com/javascript-data-grid/licensing/)

**Pricing (checked 2026-10-10)**
- "Prices are per developer": AG Grid Community free (MIT); AG Grid Enterprise $999; AG Charts Community free; AG Charts Enterprise $499; Enterprise Bundle $1,498. Enterprise and Bundle include a perpetual licence "Including 1 year of updates (see EULA)" and Zendesk support; Community support is via GitHub. — [License pricing page](https://www.ag-grid.com/license-pricing/)
- The Community Edition page: Enterprise licences are "available on a per-developer, per-deployment basis. Licences are perpetual and come with 1 year of support and updates." — [Community edition page](https://www.ag-grid.com/community-edition/)
- The v12 EULA defines "Deployment Licence" as "a licence of the Licensed Materials granted to the Licensee in addition to either the single application developer licence or multiple applications developer licence," i.e. the EULA recognizes Single Application and Multiple Application developer licences as distinct products. — [AG Grid Enterprise License v12.0](https://www.ag-grid.com/eula/AG-Grid-Enterprise-License-v12.0.html)
- Current ("Latest") EULA: clause 3.5 "Deployable Licence" permits sub-licensing "the Software Materials (other than the Source Code) to Customers," "subject to the number of Customers, Production Environments or other relevant parameter and/or limitation set out in the applicable Quote." "Production Environment" is "where the Licensee's services and/or store are made available to the Licensee's customers." Clause 3.3: the Software "must not be licensed to any third party including as part of an Application" unless a Deployable Licence applies. Clause 3.7(b): not to be "redistributed as part of any Application that can be described as a development toolkit or library." Clause 3.2: a Quote states "whether or not the Licence is perpetual or a subscription"; 12.2: Quotes "automatically renew for subsequent twelve (12) month periods"; 12.7: perpetual licensees "may continue to use the versions ... licenced prior to termination." Developers who work "with JavaScript on an Application's user interface" using the Software count as Licensee Developers (3.4). Fee increases capped at once per 12 months and "5% plus ... CPI" (4.11). — [AG Grid Enterprise License Latest](https://www.ag-grid.com/eula/AG-Grid-Enterprise-License-Latest.html)
- Third-party price intelligence (Vendr) estimates a "Multiple Application License: approximately $1,495–$1,995 per developer per year," and notes actual contract pricing varies. — [Vendr AG Grid](https://www.vendr.com/marketplace/ag-grid)

### Inferences
- Enterprise downloads at ~55-60% of Community downloads, despite Enterprise being paid, show how little friction the public-npm + watermark model adds: developers try Enterprise freely and the watermark converts production use. Enforcement is "shame-based" (visible watermark in front of end users) rather than blocking.
- The "per developer, per deployment" wording plus the EULA's "Deployable Licence" (sub-licence to Customers, limited by Customers/Production Environments in the Quote) means SaaS and OEM use is a separately priced add-on negotiated by quote, not a fixed public SKU as of 2026.
- A single founder with an MIT core, a feature-gated paid tier priced per developer, and inbound demand from banks got to two employees in year one and 1,000 enterprise customers in two years; the gated features were the "big-table" ones (pivot, grouping, server-side row model, Excel export) that enterprises need and hobbyists do not.

### Gaps
- Public list prices for the Multiple Application developer licence and the Deployment licence are no longer on the pricing page as of 2026-10-10; only the $999 single-developer figure and Vendr's $1,495-$1,995 estimate were found. (From memory, AG Grid's pre-2025 page listed Single App $999, Multiple App $1,499, and a Deployment licence add-on of $750 per production environment; I could not verify these in 2026 sources, so treat them as unverified.)
- Renewal/"support extension" pricing (historically a percentage of licence price) was not found on current pages.
- No revenue figures are published; the podcast gives only early-days numbers (£1,000/day) and customer counts.
- Whether Enterprise source is browsable in the public monorepo could not be confirmed from the README listing (only `community-modules`, `packages`, `plugins` were visible).

## All vendors: license model, free vs paid, prices and units, enforcement, trial, SaaS/OEM, size and signals

### Takeaway
Per-developer annual or perpetual-with-1-year-updates pricing clusters at $600-$1,300 per developer across the market; only SpreadJS (domain deployment fees of $1,499-$12,499/year) and AG Grid (per-deployment add-on) charge for deployments, and only Bryntum and DHTMLX publish OEM/SaaS as a distinct license class. Enforcement is almost universally an offline-validated key that produces a watermark/banner plus console warning (MUI, Kendo, Syncfusion, DevExtreme, SpreadJS off-localhost, AG Grid), with Handsontable the outlier that blocks the grid, and Bryntum/DHTMLX relying on gated distribution rather than runtime checks.

### Cited Findings

**MUI X (Pro / Premium / Enterprise)** (checked 2026-10-10)
- License model: open core. Community data grid is MIT (`@mui/x-data-grid`); Pro and Premium are commercial under the MUI X EULA. Pricing page: Pro $299/year/developer, Premium $599/year/developer, Enterprise $1,399/year/developer from 15 seats; "40+ free components," Pro adds "10+ Pro features," Premium "5+ Premium features." — [MUI pricing](https://mui.com/pricing/)
- Units: licenses must match "the maximum number of concurrent developers contributing front-end changes"; not named, transferable; volume discount from 25 developers; developers using MUI X "indirectly, such as through a wrapper library, must also be licensed." Annual: development requires an active license, production use is perpetual for versions released during the term. Perpetual option: use "forever in production and development," 12 months maintenance, renewal discounts 50% before expiry, 35% up to 60 days after, 15% beyond. — [MUI pricing](https://mui.com/pricing/)
- SaaS/OEM: licenses are royalty-free for internal, hosted, and end-user-deployed commercial solutions; sublicensing allowed when the software is part of a larger work; two cases need sales: products exposing the components so others build applications (CMS, design builder) and modules that "don't add significant primary functionality" (e.g., a theme sold separately). — [MUI pricing](https://mui.com/pricing/)
- 2026 price change (effective 2026-04-08): Pro and Premium move to single-application vs multi-application licensing; Enterprise always multi-app with minimum 15 seats; priority support Enterprise-only; security questionnaires and custom agreements for orders of $12,000+; v8 license holders can renew at old pricing; v9 needs new keys. Rationale: Pro's per-developer price "has not significantly changed since it was introduced in 2020" despite added features. — [MUI X price changes blog](https://v8.mui.com/blog/2026-mui-x-price-changes/) (Historic pricing page snapshots list Pro at $180 and Premium at $588 per developer per year, so the 2026 change raised Pro to $299. — [search summary citing v8/v6 pricing pages](https://v8.mui.com/pricing/))
- Enforcement: `LicenseInfo.setLicenseKey()` from `@mui/x-license`, called before first render; "The license key is checked without making any network requests—it's designed to be public." Missing, invalid, or expired key: the component "displays a watermark and provides a console warning in both development and production"; end users can still use it. EULA allows Pro/Premium "without a commercial license for 30 days" in non-production. — [MUI X licensing docs](https://mui.com/x/introduction/licensing/)
- Company: self-described bootstrapped; grew from 6 to 14 FTE in 2021 with financial support up 2.9x; Wellfound lists 11-50 people. — [MUI 2021 in review](https://mui.com/blog/2021/); [Wellfound](https://wellfound.com/company/mui)
- npm (week of 2026-10-02): `@mui/x-data-grid` 3,032,081; `-pro` 1,440,608; `-premium` 577,603. GitHub mui/mui-x 5,862 stars. — [npm API](https://api.npmjs.org/downloads/point/last-week/@mui/x-data-grid-pro); [GitHub API](https://api.github.com/repos/mui/mui-x)

**DevExtreme (DevExpress)** (checked 2026-10-10)
- Fully proprietary, per-developer 12-month subscription: DevExtreme Complete $899.99; ASP.NET & Blazor (includes DevExtreme) $1,099.99; DXperience $1,699.99; Universal $2,299.99. ### Inferences
- Small/bootstrapped vendors in this set: AG Grid (solo founder, self-funded until 2025), Handsoncode (11-50 staff, Polish sp. z o.o., no outside capital found), MUI (self-described bootstrapped, ~14 FTE in 2021), Bryntum (founder-run from 2009 until the 2025 PE stake), DHTMLX (small, size unclear). Syncfusion (2,000+ staff), Progress/Telerik (public company), DevExpress, and MESCIUS (~400 staff, Japanese parent) are large.
- What founders say drove sales: AG Grid credits a viral launch post, filling feature gaps (pinning, grouping), an MIT core that removed adoption friction, and gating "enterprise-only" capabilities (pivot, integrated charts, server-side rows) that banks wanted; it priced low (£250) and raised fast when a customer paid 10x for a proper licence. Handsontable's lesson is the opposite: a free tier that was too generous (1:25) could not fund the company, so it withdrew the open source license and later moved to sales-led enterprise pricing. CKEditor's founder (in the HN thread) and SheetJS both say the paid conversion rate of free users is well under 1%.
- Per-developer is the dominant unit because it is easy to audit by contract and does not require phone-home; vendors that want SaaS/OEM upside either add a deployment/domain fee (SpreadJS, AG Grid) or a separate OEM class (Bryntum, DHTMLX). MUI and Kendo explicitly waive deployment fees as a selling point.
- Public-npm distribution with an offline watermark key (AG Grid, MUI, Kendo, Syncfusion, DevExtreme) maximizes trial funnel; private-registry distribution (Bryntum, DHTMLX commercial builds) nearly eliminates public download signal, which is why their npm counts are near zero despite thousands of customers.
- For a solo developer modeling a React data-analysis component: the AG Grid/MUI pattern (MIT core, feature-gated paid package on public npm, offline public key, watermark not blocking, $300-$1,000 per developer per year or perpetual with 1 year of updates, 30-day trial, royalty-free SaaS with a negotiated OEM/toolkit exception) is the most replicated and least operationally demanding pattern in this market.

### Gaps
- Exact Enterprise/OEM prices for Handsontable, Bryntum OEM, SpreadJS Unlimited/perpetual, and MUI single- vs multi-application tiers are quote-only and not public.
- Renewal pricing for Kendo/Telerik and AG Grid is only shown inside customer accounts.
- No vendor in the set publishes revenue; the only figures are third-party estimates (Syncfusion ~$60M via GetLatka, DHTMLX ~$7M via Datanyze), both unverified.
- Syncfusion's trial length and Handsontable's pre-2019 official price list were not found on current pages.
- No founder interviews were found for DHTMLX, DevExpress, or MESCIUS on what drove sales; Mats Bryntse's statements found were limited to the Adelis announcement.
