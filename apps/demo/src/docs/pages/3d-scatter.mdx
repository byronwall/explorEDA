## When to use it

Use a 3D scatter plot when three numeric fields together describe a shape, such as a trajectory, that two axes flatten.

## How it reads

- Each point places one row by its X, Y, and Z fields. A color field and a size field can encode two more.
- Drag to orbit the scene. The camera position is saved with the chart.
- Grid planes and axes can be turned off to see the points alone.
