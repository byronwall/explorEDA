Keep the bounded owned-kernel proposal conditional on a small implementation and independent fixture conformance.
The public atom and policies remain stable if implementation instead uses a pinned library internally.
Do not copy the 699-line declaration companion as a new public API wholesale.
Use current result/diagnostic structures where clear; add only fields needed by the supported loop.

Local acceptance also adds both error-plus-missing operand orders and reversed sort ties.
The fixture sorter uses lexical IDs; the local Rows plan keeps current source order for numeric ties.
The supplied tie example agrees with both rules, so it does not prove that distinction.
