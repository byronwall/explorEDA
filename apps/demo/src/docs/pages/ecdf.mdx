## How it reads

- **Read as** plots the share of values at or below each x, or at or above it, which reads better for questions about how many exceed a value.
- **Split by** draws one curve per value of a field. Each curve uses its own rows as 100%, so groups of different sizes compare fairly. A dashed curve can show all rows together.
- Quantile marks show where each curve crosses 50% and 90%.
- When every value is positive, the X axis can use a log scale.
- An ECDF at a limit includes the values equal to it. The share at or below an upper limit is the share that passes it. A [histogram's specification limits](/docs/bar#specification-limits) count the parts that fail, strictly past each limit, so the two readings add up to 100%.

## Annotations

The **Notes** tab adds lines, bands, regions, and callouts. On x they mark a value, such as `rule x=60 "Two months"` or `band x=10..30`; on y they mark a share from 0 to 1, such as `rule y=0.5`. `rule x=median` and the other statistics read the field's values in the rows the curves draw.
