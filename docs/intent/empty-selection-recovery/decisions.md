## Local adjustments

Use **Recover rows** consistently; the originals also use Find a recovery and Try two restrictions.
Keep the original module split and time estimates as proposals, not implementation requirements.
Start with direct scans and cancellation; measure before adopting the proposed mask budget or chunk duration.
Keep memory equality and serialization work scoped to values recovery must preserve.
Do not turn the existing host callbacks into a new public precommit protocol.

The source at the cited VLDB URL is titled _A Probabilistic Optimization Framework for the Empty-Answer Problem_.
The originals call it _The New Frontier of Empty Answer Problem_. Retain the URL and correct the title in local references.
The interactive-removal argument holds; the proposed 12-unit cap is this design's choice, not a result from that paper.
