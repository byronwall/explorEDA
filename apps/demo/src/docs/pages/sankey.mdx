## How it reads

<ReadingGuide chart="sankey">
  <Part at="stage">
    Stages are category fields in order. Each row is one path through them.
  </Part>
  <Part at="flow">
    Flow width is a count of rows, or a sum of a measure. Negative and missing
    measure values are left out. Click a flow to filter every other chart to the
    rows on that link.
  </Part>
  <Part at="other">
    Each stage shows at most a set number of values, the ones with the most
    rows. The rest join one **Other** node that lists its members.
  </Part>
  <Part>
    Band heights use one scale from all rows, so when other charts filter, flows
    get thinner and each value keeps its color. Set **Scale to** to filtered
    rows to fill the plot instead.
  </Part>
  <Part>
    Rows with a missing stage are left out, or shown as their own node.
  </Part>
</ReadingGuide>
