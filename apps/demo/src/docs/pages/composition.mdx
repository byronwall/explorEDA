## Before you compose

Several report graphics are ordinary charts with a few settings. Start with the built-in chart when it answers the question, and compose when the arrangement itself carries meaning.

- **A labeled bubble scatter:** [Scatter](/docs/scatter) with a log x axis, size by a field, color by a category, and callouts in Notes keyed to a record. Compare [the scatter](/examples/income-life-scatter) with [the composed version](/examples/income-life).
- **Shares of each group's total:** [Bar](/docs/bar) with a summed group, a series split, and 100% layout. See [media and deaths](/examples/media-deaths-bar) and [Du Bois's income plate](/examples/du-bois-income-bar).
- **A stacked stream over time:** [Line](/docs/line) summed by month, split by a category, drawn as stacked areas. See [unemployment by industry](/examples/unemployment-area).

Each built-in version filters, traces, and saves like any chart. The composed versions keep their exact layout, labels, and styling.

## How it reads

- Chart units draw marks from the rows, through named scales that every repeat shares.
- Text and labels can show values computed from the data.
- A single repeat can carry its own visual changes, kept apart from the template.

## Waterfall and donut marks

A chart unit can draw a waterfall or a donut in each repeat. They compute their values as the [Waterfall](/docs/waterfall) and [Donut](/docs/donut) charts do, so a report page and the workspace show the same numbers.

- **Waterfall** bridges a start state to an end state with one signed step per category, or runs a total through ordered steps from a start value. Every repeat shares one value axis, so a quarter's deficit reads against the others. Steps can group under a field, with a hollow checkpoint for each subtotal, and the start and end draw as a line from zero to a dot.
- **Donut** shows each category's share of the repeat's rows, largest first, with the smaller categories pooled into Other. Categories keep one color across repeats, and a legend element lists them. A repeat with a negative part or no total shows no shares.
- Both trace like any mark: Alt-click a step or slice for its value, how it was calculated, and its rows.
