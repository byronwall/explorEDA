# Scatter regression product decisions

Captured from Byron’s ten response annotations on 2026-10-03.

1. **Purpose:** Understand relationships with objective measures. Show slope, offset, and R².

2. **Delivery:** Deliver regression, summaries, and density improvements sequentially as native package features.

3. **Fit population:** Own brushing changes selection only. Filters from other charts recompute the regression.

4. **Method choice:** Choose one regression method at a time.

5. **Overall fit:** Offer an overall fit alongside group fits. Default this option to off.

6. **Facet results:** Make facet equations and detailed results available without crowding the chart.

7. **Shared parameters:** Use the same method parameters across all charts in the same definition.

8. **Primary display:** Prioritize the equation and curve on the chart.

9. **Unavailable fits:** Show a warning icon with an explanation on hover.

10. **Scale:** Use about 10,000 rows across ten groups as the working target.

“Same definition” means shared chart settings across its facet instances. It does not impose workspace-wide parameters. Detailed results are inspection scope; reusable calculated fields are not yet confirmed. The row/group counts are rough targets, not capacity promises.
