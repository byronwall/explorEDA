## Small multiples

Facets repeat one chart for each value of a field, so you can compare groups side by side.

- **Wrap** lays out one repeat per value of a row variable, in a set number of columns.
- **Grid** lays out repeats by a row variable and a column variable.
- **Visible facets** chooses which repeats show, and in what order.

Turn on facets in a chart's **Facets** settings.

## Shared scales

Every repeat uses the chart's axis domains, which come from all source rows. Repeats compare on the same scales, and their positions stay put as filters change.
