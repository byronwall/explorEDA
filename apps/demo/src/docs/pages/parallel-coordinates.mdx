## When to use it

Use parallel coordinates to compare many numeric fields at once. Each row is one line across a set of vertical axes, so groups with similar profiles run together.

## How it reads

- Axes run left to right in the order you set.
- An axis can be drawn high-to-low. This changes the display only; a selection on it keeps its bounds.
- Lower line opacity helps when many lines overlap.
