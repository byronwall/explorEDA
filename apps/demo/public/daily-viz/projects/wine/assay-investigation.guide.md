# Investigate wine chemistry by cultivar

## Try this

1. Select Cultivar 3 and brush a flavanoid range; verify identical source wines in the profile and table.
2. Trace a value without assigning an invented physical unit or tasting quality.
3. Clear the cultivar selection and inspect overlap in the same numerical range.

## Limits

This is the UCI Wine recognition dataset, not the demo’s Wine Quality ratings. The publisher does not specify units for these assay fields; source units are retained. Cultivar labels are not quality rankings.
