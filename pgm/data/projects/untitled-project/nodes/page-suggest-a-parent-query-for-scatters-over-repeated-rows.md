From multi-source analysis. On an item-level query, a scatter of order fields draws each order once per item. When every scatter field comes from a looked-up parent, suggest opening a view on a query whose rows are that parent, using the Query panel helpers (sourceView, queryForStage), not chart-level identity rules. Verify with the shop example at 1280, 783, and 390 px.
