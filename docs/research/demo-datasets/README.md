# Demo dataset research

This research picked the four dataset families in the demo catalogue: January 2013 flights, Beijing air quality, World Development Indicators, and 2023 earthquakes. The demo overhaul built one complete analysis on each. The [dataset notes](../../../apps/demo/public/datasets/README.md) describe what shipped, with its sources, licenses, and preparation.

Keep this report for reserve datasets and analysis ideas the demo has not used yet:

- [Deferred candidates](dataset-research.md#7-candidates-considered-but-not-selected): UCI Bike Sharing, UCI Online Retail, UCI Concrete Strength, and UK STATS19. STATS19 is the strongest later related-table example.
- [Coverage and reporting](dataset-research.md#6-portfolio-coverage-and-notebook-reporting-readiness): chart fit and the smallest later report additions.
- The twenty proposed analysis designs, in sections 2–5. The shipped analyses use some of them. The rest are proposals, and their findings still need computing.
