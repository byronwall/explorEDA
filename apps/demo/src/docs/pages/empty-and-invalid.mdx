## No rows

When filters leave a chart with no rows, it says "No rows match the current filters." Clear a filter from the filter bar to bring rows back.

## Invalid settings or data

- When a pivot table's saved fields aren't in the data, it says which fields are missing.
- Opening a full analysis JSON that fails validation shows its errors.
- A field conversion that fails leaves those values missing. The original rows stay unchanged.
- An axis range whose minimum passes its maximum is not applied until you fix it.
