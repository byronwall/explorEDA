## How it reads

<ReadingGuide chart="heatmap">
  <Part at="rows">Rows group by one field and columns by another.</Part>
  <Part at="cell">
    Each cell's shade shows its **Metric**: a count of rows, or a sum, average,
    maximum, or minimum of a measure, such as `aggregation=max
    measureField=rate`.
  </Part>
  <Part at="values">
    **Show values in cells** prints each value inside its cell when the cell is
    large enough for the text.
  </Part>
  <Part at="selected">
    Click a cell to filter every other chart to rows with both of its values.
  </Part>
  <Part at="limit">
    Each axis shows the values with the most rows, up to **Rows shown** and
    **Columns shown** (200 each at most). Rows with other values are counted
    below the chart.
  </Part>
  <Part>
    **Order** puts values by row count, A to Z, or the order they first appear.
    **Column order** sets the columns apart from the rows.
  </Part>
</ReadingGuide>

## Long histories

Set **Column dates** on a date column to group it by year, month, week, or day. Every period from the first date to the last gets a column, so a quiet month shows as an empty cell instead of disappearing. Past the column limit, the latest periods show, and the rest are counted below the chart.

Click a cell to select its row value and the dates of its period; the other charts narrow to those exact rows.

With many columns, labels show every few columns so they never overlap. Every cell still names its row, column, and value.

See [six years of messages by month](/examples/message-log-heatmap) and [every state and year of measles reports](/examples/measles-heatmap).

## Color

By default, color runs across the shown cells' range over all rows, diverging around 0 when the values cross it. Each side of a diverging scale stretches to its own end, and the legend shows both ends. Filtering in other charts empties cells but keeps each value's color. Set **Scale to** to filtered rows to fit the colors to the rows other charts leave; the legend then says "fitted to filtered rows".

- **Color ends** fix the low and high values, so a value keeps its color whatever the filters show. Values past an end take the end's color. Set only one end to fix just that side.
- **Square-root color** spreads small values apart, which helps when a few cells are far larger than the rest. Zero stays the lowest color, and negative values mirror positive ones.
- Cells with no rows and cells with no valid measure stay apart from a measured zero, in the legend and in the trace.

See [state election margins on a fixed scale from −40 to +40](/examples/elections-heatmap).

## Annotations

A callout attaches to one cell, at its center, by the cell's row and column values: `callout "Peak" category=Tue,9`, or `callout "Peak" on=day:Tue,hour:9` with the field names. Quote a value that holds a comma. A cell holds many rows, so it never stands for one record. Both axes name categories, so a heatmap takes no lines, bands, or regions.
