## Copy and save

**Workspace actions** in the toolbar holds the export actions:

| Action                      | What it does                                    |
| --------------------------- | ----------------------------------------------- |
| **Copy settings JSON**      | Copies what every chart saves, without the rows |
| **Open settings JSON**      | Pastes settings back in                         |
| **Copy full analysis JSON** | Copies the settings and the rows together       |
| **Open full analysis JSON** | Reopens a full analysis                         |
| **Copy Data**               | Copies the rows                                 |

A composition can also **Copy PNG** of its artboard.

## Chart images

Every chart's header has an **Export image** button. **Copy image** (<kbd>E</kbd>) puts a PNG on the clipboard to paste into a slide, document, or chat. **Download image** (<kbd>Shift</kbd>+<kbd>E</kbd>) saves it as a file named from the chart title and the date.

The image matches the chart as drawn: its title, subtitle, legends, annotations, and current selection, in the workspace theme, at twice its on-screen size. Header buttons, hover readouts, resize grips, and usage hints are left out. A data table shows the rows in view. Copying needs a secure (https) page; download works everywhere.

In the demo, **Export analysis** downloads a view's charts and source rows as one JSON file, and **Export project** downloads every view, query, and source table.
