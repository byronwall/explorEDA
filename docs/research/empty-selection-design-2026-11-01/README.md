## What decides the design

A chart's context excludes its whole owning selection. A single predicate removal must retain its siblings.
The grouped-bar compiler uses the latest range; deleting it can expose an older range and exchange records.
Inventory actual stored predicates, including those hidden by the chip display rule.
Use current effective columns and complete registered owner compilers in a detached preview.
Apply requires one coherent provider publication, fresh inputs, and real edit permission.

Rows/table search and notebook selections have separate scopes.
Notebook selection recovery stays temporary. Authored changes need writer/compile preflight.
Folder saves must check exporter omissions before writing; accepted runtime state and durable file state are separate.
Keep exact typed values in memory while preserving existing JSON validation and supported normalization.
