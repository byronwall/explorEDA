Newsprint now sizes axis text on scatter and bar charts, and axis layout measures text so larger or wider type claims room instead of overlapping. Charts gain an optional `style` setting for title size, title weight, and subtitle size, axis text sizes offer a Theme option, and the Theme tab lists every chart that overrides the theme with a reset for each. Axis text now follows the theme's foreground color, so it stays readable in dark mode.
