## Scales

- **Linear** uses evenly spaced values. It is the standard scale for most charts.
- **Symmetric log** shows detail across large ranges while keeping zero and negative values. Choose it in a chart's **Axes** settings.
- **Log**: an ECDF can plot X on a log scale when every value is positive, and composition value scales can use a log transform.
- **Time**: line charts summarize dates into UTC days, weeks, months, or years.
- **Band**: category fields sit in evenly spaced bands, as in row and bar charts and box plots.

## Ticks, grids, and ranges

- Tick density sets about how many tick values an axis shows, from 2 to 12.
- Grid lines can be turned on or off for each axis.
- An axis range sets the values it shows. Leave a side blank to follow the data. Marks outside are hidden, not filtered.

## Axis titles

Set each axis title and its units in a chart's **Labels** settings. A blank title uses the field's label.
