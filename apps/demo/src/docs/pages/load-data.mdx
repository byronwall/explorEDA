## Open your data

On the demo's home page, drop a CSV or JSON file anywhere on the page, or use the upload box. The file opens through the same import path either way.

<Terms
  items={[
    ["CSV", "Opens as rows, with a field summary to start from."],
    ["Full analysis JSON", "Reopens its rows and its charts together."],
    ["Project file", "Opens several related tables as one project."],
  ]}
/>

<Callout title="Your data stays in your browser.">
  Opening a file reads it on this page. Nothing is uploaded.
</Callout>

## Start from an example

Each example opens with its data and saved views. Its URL, such as `/examples/shop-operations`, reopens the session you saved from it.
