## Shared color scales

Charts that color by the same field share its scale, so a category has one color across the dashboard.

- **Categorical** scales give each value its own color from a palette, such as Okabe Ito, Tableau 10, or the current theme's palette.
- **Numerical** scales map values onto a continuous color ramp.
- Open **Colors** in the toolbar to change a scale's palette and order. The panel warns when two colors look alike to readers with color vision deficiencies.
