## Open your data

On the demo's home page, drop a file anywhere on the page, or use the upload box. Either way, the file opens through the same reader. **Add source** in the Schema diagram reads the same formats.

| Format     | Files               | What opens                                                  |
| ---------- | ------------------- | ----------------------------------------------------------- |
| CSV        | `.csv`, `.txt`      | One table. Comma, semicolon, tab, or pipe delimiters        |
| TSV        | `.tsv`, `.tab`      | One table, split on tabs                                    |
| JSON       | `.json`             | An object or array of objects. Nested objects become fields |
| JSON Lines | `.jsonl`, `.ndjson` | One object per line                                         |

<Terms
  items={[

    ["Full analysis JSON", "Reopens its rows and its charts together."],
    ["Project file", "Opens several related tables as one project."],
  ]}
/>

A Google Sheets document opens the same way: choose **File → Download** in Sheets, pick CSV or TSV, and open the downloaded file. It opens as a snapshot and doesn't stay connected to the sheet.

<Callout title="Your data stays in your browser.">

</Callout>

## How values are read

explorEDA keeps the values your file gives it. Each column's type comes from every row in it, not just the first few.

<Terms
  items={[
    [
      "Numbers",
      "A column holds numbers only when every value converts without change. 0012 keeps its leading zeros, and a whole number too long to hold exactly, such as a 19-digit account ID, stays text.",
    ],
    [
      "Dates",
      "Date columns keep the text the file shows, such as 2025-03-01, and chart as dates.",
    ],
    ["True and false", "A column of true and false values reads as yes or no."],
    ["Blank cells", "Blank cells are missing values, not zero or empty text."],
    [
      "Nested JSON",
      "A nested object becomes dotted fields, such as user.plan. A list stays together as JSON text in one field, so each record is one row.",
    ],
  ]}
/>

A JSON file whose records sit under one key, such as `{ "data": [...] }`, opens those records. When a file can't be read, the message names the row or line, such as **Row 12 has 6 values, but the header names 5 fields.** A blank or repeated header gets a new name, such as `Column 3` or `name_2`, and the field list shows it.

To read a column another way, open the field in **Fields** and change its type.

To try it, open **Store inventory** under **No file handy?** on the home page, or download [store-inventory.tsv](/datasets/store-inventory.tsv). Its SKUs, UPCs, and ZIP codes keep their leading zeros, and its count times chart as dates. **App events** ([app-events.ndjson](/datasets/app-events.ndjson)) is JSON Lines with nested user fields and 19-digit session IDs.
