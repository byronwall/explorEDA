# Investigate cultivar chemistry without quality labels

Which assay profiles remain after selecting a cultivar and a chemical range?

## Investigation sequence

1. Select Cultivar 3 and brush a flavanoid range; verify identical source wines in the profile and table.
2. Trace a value without assigning an invented physical unit or tasting quality.
3. Clear the cultivar selection and inspect overlap in the same numerical range.

## Fixed-snapshot findings

Mean flavanoids in Cultivar 1 were 2.982 source assay units.
Mean flavanoids in Cultivar 3 were 0.781 source assay units.

## Limits

This is the UCI Wine recognition dataset, not the demo’s Wine Quality ratings. The publisher does not specify units for these assay fields; source units are retained. Cultivar labels are not quality rankings.

Eight panels contain an instruction note, six analytical/selector/metric views, and a source table. Runtime cross-filtering and trace behavior are pending local verification. The query uses one base population; related lookup totals are not additive repeated measures.
