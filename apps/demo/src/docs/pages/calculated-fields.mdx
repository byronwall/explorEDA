## Make a field from your data

Press **Calculations** in the toolbar to create and edit calculated fields. Combine values, set a rule, or extract a date. Each formula stays connected to its inputs, and its result previews before you use it in a chart.

## In charts and tables

- An ƒx marker on a chart or table field opens its formula and the chain of fields it depends on.
- The editor previews a draft before **Apply**. Inserting a field or function places it at the cursor.
- A row that lacks a field the formula uses reads that field as missing, both in the calculated values and in the row's trace. An error in a field the formula depends on, such as division by zero, still shows in the trace.
- Calculations save as formula text, such as `["Gross sales"] - ["Discount amount"]`.
- Inside `["…"]`, a field's label or the column name after its table works too: `["Sack"]` saves as `["qb_dropbacks.sack"]`. When a name fits more than one field, the error lists the ids to choose from.
- `bin(x, width)` rounds down to a multiple of width, so `bin(["Yards"], 10)` groups 0–9, 10–19, and so on. `round(x, digits)`, `floor(x)`, and `ceil(x)` round numbers.
- `region(latitude, longitude, "us-state")` names the region that contains each point: `"country"` returns an ISO alpha-3 code, `"us-state"` a postal code, and `"us-county"` a FIPS code. Add `"name"` as a fourth argument for the region's name. It computes in the browser each time the workspace opens, so results are never saved with the data.
