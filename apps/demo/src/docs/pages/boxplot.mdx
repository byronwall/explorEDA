## How it reads

- Each box spans the middle half of a group's values, with a line at the median.
- **Whisker type** sets how far whiskers reach: 1.5 times the interquartile range, the minimum and maximum, or standard deviations.
- **Show Outliers** draws values beyond the whiskers as separate points.
- **Display** can add a violin: a density shape around each box. Smoothing is automatic from each group's spread and row count, or set by hand.
- **Observations** shows individual values over each box, up to the first 300 valid rows per group.

## Annotations

The **Notes** tab adds lines and bands on the value axis, such as a specification limit or a normal range.
