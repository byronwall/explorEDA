## How it reads

- **Read as** plots the share of values at or below each x, or at or above it, which reads better for questions about how many exceed a value.
- **Split by** draws one curve per value of a field. Each curve uses its own rows as 100%, so groups of different sizes compare fairly. A dashed curve can show all rows together.
- Quantile marks show where each curve crosses 50% and 90%.
- When every value is positive, the X axis can use a log scale.
