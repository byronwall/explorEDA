## Try it

Click a category, then open **Rows** and **Fields** from the toolbar. Each panel describes the same filtered rows.

## Toolbar

- **Add chart** opens a dialog to pick a chart type and its fields, with a live preview. **Add to grid** then lets you choose where it goes; canceling adds nothing.
- **Fields** (<kbd>F</kbd>) lists every field with search, quick stats, and chart actions. <kbd>Shift</kbd>+<kbd>F</kbd> shows every field's distribution in a full view. See <DocsLink topic="fields">Fields</DocsLink>.
- **Rows** (<kbd>R</kbd>) peeks at the rows that pass every chart filter.
- **Schema diagram** shows every table, field, and relationship as a diagram, with each field's calculations and the views that read it.
- **Calculations**, **Theme**, **Colors**, **Grid**, and **Chart spec** open workspace settings: calculated fields, chart type and surfaces, color scales, grid columns and spacing, and what each chart saves.
- **Workspace actions** holds save, open, copy data, and keyboard shortcuts (<kbd>?</kbd>).
- A host app can add its own panels beside Fields and Rows, such as the demo's **Dashboard text** and **History**. One panel is open at a time.

## Chart header

Each chart's header holds its title and its tools: view data (<kbd>V</kbd>), export image, settings (<kbd>S</kbd>), duplicate (<kbd>D</kbd>), delete (<kbd>X</kbd>), trace, and details. Hover a chart, or move to it with <kbd>Tab</kbd>, to use the letter keys.

**Export image**, also on the chart's right-click menu, copies the chart to the clipboard (<kbd>E</kbd>) or downloads it as a PNG (<kbd>Shift</kbd>+<kbd>E</kbd>). The image shows the chart as drawn, at twice its on-screen size and in the current theme: title, subtitle, legends, annotations, and the current selection. Header buttons, hover readouts, and usage hints are left out. A pivot or summary table appears in full; a data table shows the rows in view.

**Details** opens the chart larger, with a hint for its gestures and tabs for its settings and the rows behind it.

When a title doesn't fit, the header says so. Widen or heighten the chart, or shorten the title. A good title states the question the chart answers, such as "How long does delivery take?".

## Filter bar

The bar under the charts shows how many rows pass every chart filter, followed by a chip for each active filter. Click a chip to jump to the chart that owns it, or remove it from the chip. **Filter** adds a workspace filter: choose a field and its values to narrow every chart, the row count, and Rows without making a chart. **Clear all filters** removes chart filters, table searches, and Rows filters at once.

## Layout

Charts sit on a grid. Drag a chart by its title to move it, and drag an edge to resize it. **Grid** sets the column count, row height, and spacing. Below 960 pixels wide, the grid flows charts two to a row, and a chart wider than half the grid takes a whole row.

explorEDA supports desktop viewports of 1024 CSS pixels or more.

## Keyboard shortcuts

Letter keys act on the chart under the pointer or the one with focus. Press <kbd>?</kbd> in the workspace for the full list, including the keys for calculations and notes.

| Key                                  | What it does                                      |
| ------------------------------------ | ------------------------------------------------- |
| <kbd>?</kbd>                         | Show keyboard shortcuts                           |
| <kbd>F</kbd>                         | Open or close the field list                      |
| <kbd>Shift</kbd>+<kbd>F</kbd>        | Show every field's distribution                   |
| <kbd>R</kbd>                         | Peek at the rows that pass every filter           |
| <kbd>Esc</kbd>                       | Close the open editor, popover, or expanded chart |
| <kbd>Tab</kbd>                       | Move between charts and their controls            |
| <kbd>S</kbd>                         | Open chart settings                               |
| <kbd>V</kbd>                         | View chart data                                   |
| <kbd>D</kbd>                         | Duplicate the chart                               |
| <kbd>X</kbd>                         | Delete the chart, after you confirm               |
| <kbd>C</kbd>                         | Clear the chart's filters                         |
| <kbd>E</kbd>                         | Copy the chart as an image                        |
| <kbd>Shift</kbd>+<kbd>E</kbd>        | Download the chart as a PNG                       |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Filter by the focused bar or category             |
| <kbd>Alt</kbd>+<kbd>Enter</kbd>      | Trace the focused title, facet, or color scale    |

## Names for assistive technology

Marks, controls, and charts have accessible names that state what they show, such as "Home: 168 rows" for a bar. The steps on this site use those names to check each example.
