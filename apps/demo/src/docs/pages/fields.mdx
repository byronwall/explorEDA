## Open the field list

Press **Fields** in the toolbar, or <kbd>F</kbd>. Each field shows its type, how many distinct and missing values it has, and a small distribution. The counts describe the rows that pass every chart filter.

## Try it

Open the field list and add a row chart of Region. The new chart counts the same rows as the others.

## Field actions

- **Add a chart of** a field offers the chart types that suit it: row chart or pivot table for categories, bar chart or scatter plot for numbers, pivot table for dates, and row chart for true and false values.
- **Inspect** a field to see its values and settings.
- **Use on a chart axis** puts the field on an axis of an existing chart.
- A field's missing count shows only the rows missing that field when clicked.
- Search narrows the list by name.

Press <kbd>Shift</kbd>+<kbd>F</kbd> to show every field's distribution in a full view.
