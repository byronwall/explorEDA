## How it reads

- **Metric** is a count of rows, or a summary of a measure field.
- **Once per** counts each value of a field once, so repeated result rows don't inflate the number.
- **Trace** shows how the value was built. With **Once per**, it counts IDs rather than rows, and lists each source row with the ID it belongs to, so you can see which rows repeat an ID already counted.
