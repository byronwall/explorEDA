## Trace a mark

Trace explains how a mark was computed: its source values, calculations, filters, scales, and position. It works on every chart type except 3D scatter plots, data tables, pivot tables, summary tables, and notes.

<Callout type="tip" title="A plain click still filters.">
  Only Alt-click and the Trace this point menu item trace. A normal click on a
  mark keeps selecting and filtering.
</Callout>
