Connecting a database now drafts its model: the project app proposes relationships from declared foreign keys and matching key names, shown dashed in the schema diagram to accept or dismiss. Add database lists row counts and columns, marks tables over the read limit, and adds several checked tables at once with one analysis of the table you pick. ExplorEdaProject takes the drafts as linkProposals, and proposeLinks is exported.
