## How it reads

- Levels are category fields from outermost in, one to three. Each row is one path through them.
- Node size is a count of rows, or a sum of a measure. Negative and missing measure values are left out.
- **Arrangement** draws the same hierarchy as a treemap, an icicle, or a sunburst.
- Nodes are colored by their first-level branch, by level, or in one color.
- Zoom into a branch to see its parts; the zoom saves with the chart.
