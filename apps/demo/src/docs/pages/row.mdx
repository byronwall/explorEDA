## How it reads

- Each bar counts the rows in one category of the chart's field.
- Click a bar to filter every other chart to that category.
- Row height stays between the minimum and maximum you set. When the rows would be shorter than the minimum, the chart shows fewer categories.
- Turn on **Use as color field** to give each category its own color from a shared scale, which other charts that color by the same field reuse.
