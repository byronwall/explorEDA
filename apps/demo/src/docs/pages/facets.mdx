## Small multiples

Facets repeat one chart for each value of a field, so you can compare groups side by side.

- **Wrap** lays out one repeat per value of a row variable, in a set number of columns.
- **Grid** lays out repeats by a row variable and a column variable.
- **Visible facets** chooses which repeats show, and in what order.

Turn on facets in a chart's **Facets** settings.

A wrap facet uses as many of its columns as fit at 260 pixels each, and rows of at least 230 pixels. Repeats past what fits move to pages. When the chart has more room than its repeats fill, the panels grow to use it. In a [notebook](/docs/notebooks), a wrap facet is drawn tall enough for every repeat, up to about 1,100 pixels, so a dozen panels show without paging.

An annotation draws in every panel unless its **Panel** setting in the **Notes** tab names one. A panel is named by its facet values, so reordering or hiding panels never moves a note to another group. A calculated line reads each panel's own rows, so each panel draws its own value.

## Shared scales

Every repeat uses the chart's axis domains, which come from all source rows. Repeats compare on the same scales, and their positions stay put as filters change.
