# Chart image export proof

The [first proof](first-proof/README.md), October 11, showed that one generic DOM rasterizer reproduces mixed Canvas, SVG, and HTML chart panels. It became the default capture strategy for chart image export (#340, #341, #350). `pnpm export-proof` (`scripts/export-proof.mjs`) is the maintained version of these scripts. See [Export](../../../apps/demo/src/docs/pages/export.mdx).
