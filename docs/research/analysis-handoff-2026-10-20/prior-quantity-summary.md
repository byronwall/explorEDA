## What changes the direction

Keep the existing local selection/export/undo/reopen proof first. Then consider one named scientific task with current controls and upstream preparation. If both work, stop. A failed lesson can justify one narrow comparison; it does not justify a quantity engine.

Preserve source numbers in a separate field. Name each derived quantity, reference, row meaning and missing-value rule. Absolute temperatures, differences, annual totals and centered concentrations need distinct explanations. Matching suffixes cannot establish those meanings.

The inspected daily loader does not read the corpus field sidecars. Table CSV contains identifiers and scalar values without field descriptions. Those are source boundaries, not demonstrated defects. The downstream task must decide which context it needs.
